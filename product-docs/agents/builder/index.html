Agent builder overview

The parts every Oliv AI agent is built from, from the marketplace where agents live to the detail page, instructions, tools and run modes, triggers, knowledge and run history.

The agent builder is where you see what an Oliv AI agent is and how it works. Every agent with a detail page shows the same parts: its purpose, its actions, what starts it, the files it reads and its past runs. This section explains each part, starting with the marketplace where agents live.

Where agents live: the marketplace

Open Agents in the main sidebar to reach the marketplace, the single place you see every agent available to you. Each agent is a card with a picture, a name, a short description and one button. View Agent opens that agent's detail page, and Back to Marketplace at the top brings you back. Clone Agent appears on template agents, as the way to take one as a starting point.

A search box at the right matches what you type against each agent's name and description. The Oliv AI agent marketplace on oliv.ai shows the pre-built agents grouped by the roles they serve.

Categories and badges

Agents are grouped by the revenue team they serve. Five buttons above the grid narrow the list: All, Our Agents, Sales, Revenue Operations and Customer Success. The category buttons and the search box work together, so an agent must match both to stay listed.

Some cards also carry a Pre-built or Custom badge, which tells you where that agent came from. A chat with Oliv AI's Oliver agent sits on the right of the marketplace, so you can ask about agents without leaving the screen. The panel has its own new chat and history buttons, a suggested question to start from and the Ask before acting setting under the message box.

The parts of an agent

An agent's detail page opens on its Overview tab. It summarizes the agent's goal, triggers, tools, knowledge and recent runs. A Run Agent button at the top right starts a run by hand. Each of the other tabs goes into one part in depth.

PartTabWhat it tells you
InstructionsInstructionsThe agent's Objective, its numbered Process steps and its Output
Tools and run modesToolsEach action the agent may take, and how freely it takes it
Triggers and schedulesTriggersThe events and fixed times that start the agent on its own
Knowledge filesKnowledgeThe files the agent works against, each one open to view
Run historyRunsEvery run, with a full record of what the agent did

Every agent's page has Overview, Instructions, Tools and Runs. Triggers, Knowledge and Data appear only on agents that use them. Some agents add a tab of their own, such as Moments on Oliv AI's Content Curator agent, or Sequence on an agent that runs outreach in steps.

Read the parts in order and you have the whole agent. The instructions say what it does, the tools say what it may touch, and the triggers say when it acts. The run history shows what actually happened.

How much freedom an agent has

Two settings decide how far an agent goes on its own.

  • Per tool. On the Tools tab, Auto Run acts without asking, Requires Approval waits for a person to confirm, and Agent Decides judges whether to ask.
  • Per conversation. In a chat with Oliv AI's Olivia agent, each conversation is set to Ask before acting or Act without asking.

Every run leaves evidence. Its record shows what that run produced: each email the agent wrote in full with the contacts it picked, a clipped call with its transcript, each step of an outreach sequence, or a drafted reply with the deal context behind it. So you can check an agent's past runs before you give it more freedom. CRM updates follow the same path, from reviewed to automatic, in keep the CRM updated.

How agents work together

Agents don't work alone. Oliv AI's Olivia agent runs the frontline and routes work to the right specialist agent. Oliv AI's Oliver agent keeps the playbook current and configures which agents are active, what they monitor and what thresholds trigger their actions. Each agent gets the right tools, memory, permissions and guardrails for the job, scoped to the task at hand.

One shared record

Every agent and every rep works from the same context graph. Agents also start from the data you already have. Olivia reads what's already there, messy data included, and Oliv AI's Forecaster agent doesn't need a clean CRM to start. When you override one of Forecaster's recommendations, it learns from that feedback.

Thresholds and delivery

Some agents let you tune when they speak up. With Oliv AI's Deal Driver agent, inactivity windows, field completion requirements and deal value thresholds are configurable per manager or per team. Agents deliver work where people already are: Deal Driver reaches you in Slack, email or the Oliv AI app. Tools in the catalog act in systems such as Salesforce and HubSpot.

Custom agents

The marketplace on oliv.ai offers pre-built agents designed for specific challenges, and invites you to request a custom agent. Oliv AI's GTM engineering team stays with you after launch. It reviews agent output, tunes the playbook and adds custom agents as your territory, comp or ICP shifts, as the RevOps page describes. A custom agent has the same parts as every other, so the pages in this section apply to it. The build vs buy guide covers when a custom agent makes sense.
