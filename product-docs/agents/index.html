Agents overview

How Oliv AI's agents fit together, from Olivia and Oliver, the two agents you talk to, to the specialist agents they hand work to and the parts every agent is built from.

Agents are the product at Oliv AI. You talk to two of them, Oliv AI's Olivia agent and Oliv AI's Oliver agent. They pass focused work to specialist agents for deals, the CRM, meetings, forecasts and coaching. Every agent works as a layer on top of the CRM you already use, and keeps it updated.

How the agents fit together

Oliv AI's agents work in three layers. At the front, Oliv AI's Olivia agent runs the work and Oliv AI's Oliver agent sets the rules. Oliver configures how the agents work, and Olivia coordinates their tasks across your team.

LayerAgentsWhat the layer does
The agents you talk toOlivia and OliverAnswer questions, hand off work and keep the process rules
Specialist agentsDeal Driver, CRM Manager, Meeting Assistant, Forecaster, CoachEach owns one job and reports back
Agent partsInstructions, tools, triggers, knowledge, run historyWhat every agent is built from, and the record of what it did

All of them read from one shared record. Oliv AI wires your CRM, calls, email, tickets and product usage into one context graph. Every agent and every rep works from that same graph.

The two agents you talk to

Which one you work with depends on whether you run deals or run the process. Both sit in the agent picker on the Ask tab of Home.

Olivia runs the work

Oliv AI's Olivia agent is the one reps, SDRs, CSMs and account managers talk to. You ask in plain language about a deal, a meeting or your pipeline. She answers, or hands the task to a specialist agent and reports back. Each conversation is set to Ask before acting, the default, or Act without asking. Her role across the revenue team is set out on oliv.ai.

Oliver keeps the rules

Oliv AI's Oliver agent is for RevOps managers and revenue leaders. It keeps the process handbook, from your ICP and personas to your methodology and approval rules, and every other agent works inside it. You describe a change in plain language. Oliver proposes the update as Pending Review, waits for a person to approve it, then passes it to every agent that depends on it. Its approach to your sales process is on oliv.ai, and its chat also sits beside the Agents marketplace.

The specialist agents

Each specialist agent owns one job. It does that job in the background and delivers the result where you already work, such as Slack, email or the Oliv AI app.

  • Oliv AI's Deal Driver agent watches the team's pipeline for sales managers. It sends a morning brief, alerts during the day when a deal needs attention, and a summary at the end of the day. Each week it also prepares a 1:1 report for every rep.
  • Oliv AI's CRM Manager agent writes what changed after each meeting, call and email to Salesforce, HubSpot or Zoho. Reps accept or reject each suggested field beside its current value, until RevOps switches the agent to Auto-Pilot. First, map your custom CRM fields so each update lands in the right place.
  • Oliv AI's Meeting Assistant agent sends a one-screen brief 30 minutes before each deal meeting. After the call, it drafts the follow-up email, proposes CRM updates and flags qualification gaps.
  • Oliv AI's Forecaster agent drafts each rep's forecast from the pipeline before anyone logs in. It flags the deals that don't add up and learns from how your deals actually close.
  • Oliv AI's Coach agent scores every recorded call against your scorecards. Each month it recommends three behaviors per rep, the manager picks one goal, and Coach tracks it weekly.

The Oliv AI agent marketplace groups agents by the roles they serve, from SDRs to RevOps.

Browse agents in the app

Agents in the sidebar opens the marketplace. Filter pills narrow it to All, Our Agents, Sales, Revenue Operations or Customer Success, and Search... matches an agent's name or description. Each card carries View Agent or Clone Agent, and some carry a Custom or Pre-built badge. Oliver's chat sits on the right.

Where agents get their context

An agent can only act on what it can read. Three sources feed it.

  • Conversations. The Converse app captures online meetings, phone calls, email and Slack. Bot and botless recording decides how each meeting is recorded.
  • Your CRM. Deals, contacts and fields come from Salesforce or HubSpot, and agents write updates back.
  • Your tools. Meetings come in through the Zoom integration, and Slack is where many agents deliver their work.

You don't need a clean CRM to start. Oliv AI's Olivia agent reads what's already there, messy data included.

Inside every agent

Every agent with a detail page is built from the same five parts. On the page they sit on tabs: Overview, Instructions, Tools, Triggers, Knowledge, Data and Runs, with Back to Marketplace above. The agent builder overview explains how they fit together.

  • Agent instructions state the agent's objective, the steps it follows and what it produces.
  • Tools and run modes list the actions an agent may take, each set to Auto Run, Requires Approval or Agent Decides.
  • Triggers and schedules are the events and fixed times that start an agent without anyone pressing anything.
  • Knowledge files are the documents an agent works against, such as an ICP document or a solution deck.
  • Run history records every run, with each email the agent wrote and each change it made.

Where to start

  • Prepare for a meeting: get the deal brief before each call.
  • Record a meeting and follow up: turn a finished call into a follow-up and CRM updates.
  • Keep the CRM updated: move from reviewed updates to automatic ones.
  • Run a pipeline review: walk into each 1:1 with a per-rep report.
  • Run deals as an account executive: see how the agents share one AE's week.
  • Plans and seat roles: match each person on your team to a seat role.
