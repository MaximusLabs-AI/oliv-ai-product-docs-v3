# Capabilities

Every Oliv AI capability in one catalog, grouped by agents, agent building, autonomy, conversation capture, opportunity and account management, add-ons, context and integrations.

- Applies to: Anyone mapping Oliv AI's capabilities to their needs
- Status: Live
- Verified: 2026-10-22
- Canonical page: https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/capabilities/

This catalog lists what Oliv AI does, grouped the way the product is organized. Each row says what the capability does and links the docs page that covers it, where one exists. Oliv AI's agents do the work, and every capability below feeds them or shows you what they did.

## At a glance {#at-a-glance}

| Group | What it covers |
|---|---|
| **Agents** | The two agents you talk to and the specialist agents they hand work to |
| **Agent building** | The marketplace, instructions, tools, triggers, schedules, knowledge, data and sequences |
| **Autonomy and review** | Run modes, approval, drafted emails, run history, the agent feed and scheduled reports |
| **Conversation capture** | Meetings, phone calls, in-person meetings, email and Slack, in the Converse app |
| **Opportunity management** | Deals, companies and contacts in **Records**, plus forecasting in the Forecast app |
| **Account management** | Customer health, churn risks, renewals and expansion, in the Retain app |
| **Add-ons** | Enable for coaching and clip libraries, Engage for outreach and dialling |
| **Context layer** | The capture, graphs, playbook and models every agent reads from |
| **Integrations and surfaces** | CRMs, meeting platforms, Slack, Outlook, Chrome and the iPhone app |

## Agents {#agents}

Agents are the product. You talk to two of them, and they pass focused work to specialist agents.

### The agents you talk to {#agents-you-talk-to}

| Capability | What it does |
|---|---|
| [Oliv AI's Olivia agent](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/olivia/) | Your **Chief of AI Staff**. You ask in plain language, and she answers or hands the work to a specialist agent and reports back |
| [Oliv AI's Oliver agent](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/oliver/) | Your **Chief GTM Engineer**. It studies how the team operates and keeps the playbook every other agent follows up to date |

### Specialist agents {#specialist-agents}

| Capability | What it does |
|---|---|
| [Oliv AI's Deal Driver agent](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/deal-driver/) | Tracks deals, flags risks, sends a weekly pipeline update and loops in sales managers at key moments |
| [Oliv AI's CRM Manager agent](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/crm-manager/) | Creates and enriches accounts and contacts, updates fields and creates deals from your qualification criteria. You can map your custom CRM fields for it |
| [Oliv AI's Meeting Assistant agent](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/meeting-assistant/) | Prepares you for meetings, takes notes, assigns action items and sends the follow-up email |
| [Oliv AI's Forecaster agent](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/forecaster/) | Rolls up call, upside, commit and best case, with AI notes on risks and changes |
| [Oliv AI's Coach agent](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/coach/) | Maps skill gaps per rep, prescribes small coaching tasks and tracks progress weekly |
| Oliv AI's Content Curator agent | Finds the call moments that match your enablement priorities, clips them and sends them to the right people |
| Oliv AI's Prospector agent | Builds tailored outreach and runs campaigns to turn target accounts into pipeline |
| Oliv AI's Researcher agent | Researches accounts and buyers for ICP fit and context, and develops a point of view |
| Oliv AI's Portfolio Manager agent | Tracks CSM portfolios across implementation, onboarding and success, and flags accounts that need attention |
| Oliv AI's Gold Digger agent | Finds expansion signals across your accounts |

The agent marketplace on oliv.ai groups agents by the roles they serve, and lets you pick a pre-built agent or create your own.

## Agent building {#agent-building}

Every agent with a detail page is built from the same parts. The [agent builder overview](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/builder/) shows how they fit together.

| Capability | What it does |
|---|---|
| **Agent marketplace** | One place to see every agent available to you, as cards you can filter by category or search |
| **Categories and persona filters** | Filters for **All**, **Our Agents**, **Sales**, **Revenue Operations** and **Customer Success** |
| **View Agent and Clone Agent** | **View Agent** opens an agent your organisation runs; **Clone Agent** copies a pre-built one to start from |
| **Pre-built and Custom badges** | A badge on a card shows where that agent came from |
| [Instructions](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/builder/instructions/) | The agent's objective, process and output, with each process step naming the tool it uses |
| [Tools](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/builder/tools-and-run-modes/) | The actions an agent may take, such as looking up a record, drafting an email, posting to a channel or updating a field |
| [Triggers](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/builder/triggers/) | The events that start an agent on auto-pilot, without anyone pressing anything |
| **Schedules** | Fixed times when an agent acts, set by name, frequency, day and time on the same tab as triggers |
| [Knowledge files](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/builder/knowledge/) | The background reading an agent works against, such as an ICP document or a solution deck |
| **Data sources** | The CRM objects, activity history and insights an agent reads, shown field by field so you can see what it knows |
| **Sequences** | Outreach planned over days and across channels, laid out as a numbered timeline of steps |

## Autonomy and review {#autonomy-and-review}

You decide how much freedom an agent has, and you can check every action it took.

| Capability | What it does |
|---|---|
| **Run mode per tool** | Each tool is set to **Auto Run**, **Requires Approval** or **Agent Decides** on the agent's **Tools** tab |
| **Run Agent** | Runs an agent by hand from its detail page, beside the runs its triggers start |
| **Ask before acting** | A conversation with Olivia or Oliver is set to **Ask before acting** or **Act without asking** |
| **Drafted email review** | When an agent writes an email instead of sending it, a person reviews the draft and presses **Send** |
| [Run history](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/builder/run-history/) | Every time an agent worked: when it ran, how it started and how it ended |
| **Run details** | For one run: the people it touched, the exact text of every email, any meeting booked and a timestamped list of changes |
| **Agent Feed** | One stream of everything your agents have done, with items that need you grouped under **WAITING ON YOU**. Filter it by **Team**, **Role**, **Agents** and **Timeline** |
| **My Reports** | Reports agents deliver on a schedule, beside an analyst report **Library** under **Reports** |

## Conversation capture {#conversation-capture}

The [Converse app](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/apps/converse/) captures customer conversations and turns them into searchable records. It's built to understand context, not just track keywords.

| Capability | What it does |
|---|---|
| **Botless meeting capture** | Records through the meeting platform when your company organizes the meeting. [Bot and botless recording](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/apps/converse/recording-modes/) explains the modes |
| **Bot-based meeting capture** | A meeting assistant joins the call, including externally hosted meetings when permitted. Priced as an add-on |
| **Phone call capture** | Captured phone calls sit in the **Calls** list beside your meetings |
| **In-person meeting capture** | Through the mobile app. Sell and Grow also support Plaud recordings, with the hardware bought separately |
| **Email capture** | Email threads join the same record as your calls |
| **Slack, WhatsApp and LinkedIn capture** | Conversations on these channels join the record, each priced as an add-on |
| **Meeting transcription** | Every conversation transcribed, with every speaker labeled |
| **AI summaries and action items** | A summary and next steps, ready as soon as the call ends |
| [Conversation library and search](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/apps/converse/meetings/) | Every captured meeting in one list under **Activities**, with **My meetings** and **Team meetings** views |
| [Meeting record](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/apps/converse/meeting-details/) | The recording, transcript, notes, AI summary and next steps for one meeting |
| [Clips](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/apps/converse/clips/) | A **Clip** button on a meeting's recording saves a moment into a clip library, each set to **Public** or **Private** |
| **Meeting notes in the CRM** | The AI summary and full transcript attached to the opportunity record |

## Context layer {#context-layer}

Every agent and app reads from the same context. This layer is why one captured call can shape a follow-up, a CRM update and a coaching note.

| Capability | What it does |
|---|---|
| **Context capture** | Captures calls, emails, Zoom meetings, messages and in-person meetings, enriched with ZoomInfo, 6Sense and LinkedIn data |
| [Context graph](https://www.oliv.ai/context-graph) | Connects every conversation, message and activity to the right people, account and opportunity |
| [Process graph](https://www.oliv.ai/process-graph) | Learns your product, qualification criteria, processes and exceptions, and documents them as a playbook agents follow. You edit it in **Playbook**, with Oliver beside it |
| [Signal graph](https://www.oliv.ai/signal-graph) | More than 100 specialized small language models, each answering one revenue question as new information arrives |
| **Always-on agents** | Agents run in the background, start work from signals and schedules, and collaborate with your team and each other |
| **Context sync** | Brings account and opportunity context back into Salesforce, Snowflake, Databricks or Redshift |

## Common questions {#common-questions}

#### Which capabilities come with every plan? {#faq-every-plan}

Oliv AI's Olivia and Oliver agents, reviewing conversations, opportunities and accounts, and building custom agents. Agent use is billed through credits on every plan.

#### Which plan adds forecasting? {#faq-forecasting}

Sell. It brings the Forecast app, with opportunity grids, methodology tracking, forecast boards and forecast submissions.

#### Which plan adds customer health and churn risk? {#faq-health}

Grow. It brings the Retain app, with health scorecards, churn risks and retention forecast boards.

#### Can I build my own agent? {#faq-build-agent}

Yes. You can pick a pre-built agent from the marketplace or create your own, from instructions, tools, triggers and knowledge.

#### Can agents act without approval? {#faq-approval}

Only when you allow it. Each tool is set to Auto Run, Requires Approval or Agent Decides, and each conversation is set to Ask before acting or Act without asking.

#### How do I see what an agent did? {#faq-what-agent-did}

Open the agent's run history. Each run shows the people it touched, the emails it wrote and the changes it made.

#### Which meeting platforms does Oliv AI record? {#faq-platforms}

Zoom, Google Meet and Microsoft Teams, which it joins automatically, and Webex through the Webex App Hub.

#### Does Oliv AI replace my CRM? {#faq-crm}

No. Oliv AI works as a layer on top of your existing CRM. It brings the context together and keeps your CRM updated.
