What Oliv AI is

Oliv AI builds AI agents for revenue teams. It works as a layer on top of the CRM you already use, not as a replacement for it. The agents work alongside your team to prospect, close, retain and expand revenue.

You ask for work in plain language. Oliv AI's Olivia agent runs the day-to-day work and hands tasks to specialist agents. Oliv AI's Oliver agent keeps the rules: your stages, ownership and handoffs.

Everything starts from one sidebar: Home, Agents, Apps, Reports, Records and Activities, with Playbook and Settings at the bottom. Home has two tabs. Ask is where you talk to Olivia or Oliver, and Agent Feed is one stream of what your agents have done.

Agents

Agents are the product. Each one owns a part of the revenue workflow. Oliv AI's Deal Driver agent watches the pipeline and tells managers which deals need attention. Oliv AI's CRM Manager agent fills CRM fields from calls, emails and meetings, and you can map your custom fields so updates land in the right place.

Each agent posts its work to the Agent Feed, which you can filter by team, role, agent and time.

Oliv AI's Meeting Assistant agent prepares you before a meeting and drafts the follow-up after it. Oliv AI's Forecaster agent drafts each rep's forecast, and Oliv AI's Coach agent scores calls and sets a goal for each rep.

How an agent is built

Agents in the sidebar opens the marketplace, where you filter agents by team or search by the job they do.

The agent builder shows what each agent is made of. Its tools and run modes decide which actions run on their own and which wait for approval. Triggers start an agent when something happens, knowledge files give it your material, instructions spell out its process, and run history records what it did.

Apps

Oliv AI's apps group the screens each role works in. In Converse, the meetings list and meeting details hold every recorded call. In the sidebar, meetings and calls sit under Activities. Clips save the moments worth sharing, and recording modes cover recording with or without a bot.

Workflows and use cases

Workflows follow a deal's week across several agents: you record a meeting and follow up, keep the CRM updated between meetings and run a pipeline review at the end of the week.

Use cases start from a role. Running deals as an account executive shows how one AE uses the agents across a week of calls.

Integrations and plans

Oliv AI's integrations bring in the context agents work from: HubSpot as well as Salesforce for the CRM, Zoom for meetings and Slack for summaries and alerts. Plans explain how seat roles, add-ons and agent actions fit together. Prices are on the Oliv AI pricing page.
