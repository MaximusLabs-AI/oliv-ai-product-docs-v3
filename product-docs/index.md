# Oliv AI product documentation

How Oliv AI works, page by page.

- Applies to: All plans
- Status: Live
- Verified: 2026-10-21

Oliv AI's product documentation explains what each Oliv AI agent does, how to set it up, and how it compares with other revenue tools. Oliv AI builds AI agents for revenue teams that work as a layer on top of your CRM.

## Agents {#agents}


  - [Olivia agent](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/olivia/): Ask questions about your deals and day, and hand Olivia work such as meeting prep and follow-ups.
  - [Deal Driver agent](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/deal-driver/): Daily briefs, deal risk alerts and weekly 1:1 reports for sales managers.


## Agent builder {#agent-builder}


  - [Agent tools and run modes](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/agents/builder/tools-and-run-modes/): Set each tool to Auto Run, Requires Approval or Agent Decides.


## Workflows {#workflows}


  - [Prepare for a meeting](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/workflows/prepare-for-a-meeting/): The deal brief before each call, and research on contacts you haven't met.


## Use cases {#use-cases}


  - [Run deals as an account executive](https://maximuslabs-ai.github.io/oliv-ai-product-docs-v3/product-docs/use-cases/ae-run-deals/): Prepare for deal meetings, follow up after calls and keep the CRM current.
