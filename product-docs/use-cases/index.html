Use cases show Oliv AI from one role's point of view: which agents do the work, which workflows that role runs, and how it adds up across a week. The first one built is running deals as an account executive. For every other role, this page points you to the agent and workflow pages that role uses most.

How the docs are organized

The docs answer three kinds of question, in three layers:

LayerThe question it answersStart with
AgentsWhat does this agent do, and how do I set it up?The agent pages, one per agent
WorkflowsHow do I get one job done from start to finish?A guide that follows the job across agents
Use casesWhat does Oliv AI do for my role?A role's week, with links to both

Integrations, apps and plans sit alongside these layers. They cover the tools Oliv AI connects to, the Converse app for captured conversations, and the seat each person needs. Oliv AI works as a layer on top of your CRM, so every role reads from the same record.

The product follows the same split. On Home, the Agent Feed filters by Team (Sales, Sales Development, Customer Success or RevOps) and by Role (Contributor or Manager). Each choice shows the agents that work for that role and the updates they posted.

Account executives

Account executives get the most built-out path. Oliv AI's Meeting Assistant agent sends a brief before each meeting on an active opportunity, then drafts the follow-up after the call. Oliv AI's CRM Manager agent turns what was said into field updates you approve. The account executive use case shows how those pieces fit across a deal.

To go deeper, read the Meeting Assistant agent and CRM Manager agent pages. The recording and follow-up guide covers what happens after each call. Oliv AI's own page for account executives gives the wider picture.

Sales managers and sales leaders

Managers work from the same deals, seen at team level. Oliv AI's Deal Driver agent sends a morning brief, alerts when a deal needs attention, and a prep report for each rep before their 1:1. Oliv AI's Forecaster agent pre-drafts each rep's forecast, and managers add their own adjustments before the team number rolls up. Oliv AI's Coach agent scores every recorded call and recommends three goals per rep each month, and the manager sets one.

The Deal Driver, Forecaster and Coach agent pages cover each one. The pipeline review guide puts them together in one weekly meeting. More for sales managers is on oliv.ai.

Sales development

SDRs and BDRs book and run first calls, so preparation and capture matter most. Oliv AI's Olivia agent researches the company and the person before a first meeting, and the meeting preparation guide shows that brief. The Zoom integration records those calls, whoever hosts them. Deal Driver's briefs and reports work across BDR and AE pipelines, so BDR leads use it the same way sales managers do. See Oliv AI for sales development teams.

Customer success and account management

CSMs and account managers work with Oliv AI's Olivia agent too. Before every call she has the full account history ready, and the Olivia agent page shows how to ask her for it. Oliv AI's CRM Manager agent tracks renewals, QBRs and CS check-ins as well as sales cycles.

When you take over an account, the recorded handover call gives you its summary and next steps. The Slack integration suits teams that run their day from a shared channel. If a customer asks for no meeting bot, Oliv AI records botlessly when your company organizes the call. Oliv AI's Portfolio Manager agent is the customer success equivalent of Deal Driver, applied to the renewal book. In a CS manager's feed, it posts the 1:1 agenda with the accounts at renewal risk. Read more for customer success and account management teams.

Revenue operations

RevOps sets the rules and keeps the data clean. Oliv AI's Oliver agent keeps the process handbook: your ICP, personas, approval workflows and sales methodology. The CRM upkeep guide and CRM field mapping cover how updates reach the right fields. The Salesforce integration page covers the install.

The RevOps feed brings these together: Oliver's review with changes ready to approve, CRM Manager's count of updates applied and held for review, and Forecaster's category shifts.

When you build or check agents, agent triggers set what starts them and run history shows what each run did. Planning a rollout starts with plans and seat roles. There's more on Oliv AI for revenue operations.

Enablement

Enablement managers use Oliv AI to ramp reps and keep training current. The Coach page shows how call scores turn into one goal per rep each month. The clip library collects the moments you describe, such as pricing objections, from real calls. Agent knowledge files hold the background reading an agent works against, such as a buying-committee profile or a solution deck.

Finding your role

Start with the section for your role above. If you own deals, begin with the account executive use case. If you manage people, begin with the pipeline review. If you run the systems, begin with Oliver and CRM upkeep. Each page links on to the agents and workflows it depends on.
